# Sn1p.win

Personal site for **Sn1p** — Rust server owner & creator (OneGrid Rust). Live at [sn1p.win](https://sn1p.win).

A static site: animated video backgrounds, music, and a custom profile card.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page (`Sn1p`) |
| `stallwarrior.html` | Stall Warrior page |

## Assets

- **Video:** `bg.mp4`, `sw-bg.mp4`, `pfp.mp4`
- **Audio:** `music.mp3`, `sw-music.mp3`
- **Images:** `avatar.png`, `autoturret.png`, `pfp-poster.jpg`, `stallwarrior-avatar.png`, `favicon.png`, `favicon-32.png`

## Running locally

It is a static site — serve the folder with any web server:

\`\`\`bash
python3 -m http.server 8000
# then open http://localhost:8000
\`\`\`
